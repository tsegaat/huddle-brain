# Entries

One file per shared chat: `entries/<person>/<YYYY-MM-DD>-<goal-words>.md`.

The routine writes these; you don't need to. Each one holds a one-line `goal`, the `## Decisions` made to reach it (each with **Why** and **Instead of**), and `## Still open`. The scout reads the `goal:` lines first and opens only the entries that line up with what someone is working on.

You can edit or delete any of your own files here.
